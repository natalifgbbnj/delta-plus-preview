# ДЕЛЬТА ПЛЮС — передача проекта

Состояние на 29 сентября 2026 года. Этот репозиторий — рабочий прототип сайта упаковочной и полиграфической компании ДЕЛЬТА ПЛЮС. Главная ссылка для заказчика: https://natalifgbbnj.github.io/delta-plus-preview/ . Заказчица — Наталья Альбертовна. Прототип подготовлен для согласования, не является финальным сайтом компании.

## С чего начать в Claude

1. Прочитай этот файл целиком.
2. Изучи файлы сайта в корне репозитория: `index.html`, остальные страницы `*.html`, `style.css`, `site.js`, изображения и шрифты.
3. Открой текущий прототип по ссылке выше и сохрани уже принятую структуру и визуальный стиль. При новых изменениях редактируй существующий сайт, не пересоздавай его с нуля.
4. Перед коммерческой публикацией запроси у заказчицы подтверждение контента по `project-handoff/client-checklist.md`.

## Структура и публикация

- GitHub Pages публикует ветку `main` из корня репозитория. Публичный адрес остаётся `https://natalifgbbnj.github.io/delta-plus-preview/` после каждого коммита в `main`.
- Статический сайт состоит из 8 страниц: главная, каталог, бизнесу, частным клиентам, производство, о компании, контакты, расчёт проекта. Корневые `*.html` — опубликованная версия; пути к файлам уже учитывают префикс `/delta-plus-preview/`.
- Для локального запуска без сборки: клонировать репозиторий в папку `delta-plus-preview`, перейти в её родительскую директорию, запустить `python3 -m http.server 8000` и открыть `http://localhost:8000/delta-plus-preview/`.
- Отдельная приватная версия Sites имеет адрес `https://delta-plus-modern.natalisolnechnaya.chatgpt.site/` и может требовать авторизацию. Её снимок исходников и манифест — в `project-handoff/sites-source.zip`. Публичный GitHub Pages — основная ссылка для заказчика.

## Согласованное направление

- Текущая концепция — современная предметная эстетика с крупной фотографией, спокойным фоном, красно-жёлтыми акцентами логотипа и шрифтом Onest. Слоган на главной: «Когда идея обретает фактуру».
- Для двух аудиторий есть отдельные маршруты: B2B и частные заказчики. Каталог включает упаковку, этикетки, полиграфию, книги и специальные изделия. Страница производства показывает процесс и технологии. В футере — контакты и Яндекс Карта.
- Главная ведёт к запросу на расчёт. На мобильном экране есть фиксированные действия «Рассчитать» и «Позвонить».
- По прокрутке блоки мягко появляются, а изображения чуть смещаются. Анимация не включается при системной настройке уменьшения движения. Слайдер можно остановить.
- Сайт отзывчивый. Существующую типографику, цветовую схему, галерею и мобильную навигацию следует сохранять, если нет нового задания на переработку.

- Фотографии частично иллюстративные, часть взята из открытой галереи компании. Не приписывать изображениям конкретные результаты, бренды или клиентов без разрешения.
- Контактные данные и перечни услуг перенесены с действующего сайта компании, но требуют подтверждения: Москва, ул. Каховка, 20А, офис 325; +7 (495) 661-44-28; +7 (962) 948-35-20; deltaplus-upakovka@mail.ru; Пн–Пт 10:00–19:00.
- Заявка сейчас формирует письмо через `mailto:`. Заполнение формы само по себе не отправляет данные на сервер. До рабочего запуска нужно согласовать способ приёма заявок, получателя, политику обработки данных и тексты согласий.
- Не публиковать цены, сроки, минимальные тиражи, оборудование, гарантии и кейсы как подтверждённые факты до получения материалов от заказчицы. Текущие формулировки о технологиях и составе оборудования надо перепроверить.
